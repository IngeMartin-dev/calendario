# Calendario de Adviento

Regalo de 9 meses: 28 puertas, una por día, del 27 de noviembre al 24 de diciembre de 2026. Cada puerta se abre sola cuando llega su fecha.

## Cómo verlo

Abre `index.html` en el navegador, o activa GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

Para probar todas las puertas antes de tiempo, agrega `?todos=1` a la dirección. Para el regalo real, usa la dirección sin eso.

## Cómo personalizar

Los mensajes están en la lista `MSGS` dentro de `index.html`. Cada entrada es `[título, mensaje]`; puedes cambiar cualquiera por un recuerdo propio.
